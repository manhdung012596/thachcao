Hướng Dẫn Tự Động Cập Nhật Vercel 100%

Khi bạn nhấn nút "Lưu & Cập Nhật Lên Vercel", hệ thống sẽ tự động cập nhật file dữ liệu của website. Để Vercel tự động build lại website chỉ sau 20 giây mỗi khi bạn sửa bài viết, hãy làm theo 1 trong 2 cách cực kỳ đơn giản sau:

Cách 1: Thêm GitHub Token vào Vercel (Khuyên dùng)

  1. Vào tài khoản GitHub của bạn » Settings » Developer Settings » Personal access tokens (classic) » Chọn Generate new token (chọn quyền repo).
  2. Mở bảng điều khiển Vercel của dự án » Settings » Environment Variables.
  3. Thêm 2 biến môi trường:
    • GITHUB_TOKEN: Dán token vừa tạo ở bước 1.
    • GITHUB_REPO: Tên repo dạng tên-user/tên-repo (ví dụ: yourname/thachcao).
  4. Xong! Từ nay mỗi khi bạn thêm dự án trên trang này, Vercel sẽ tự động commit và làm mới web sau 30 giây!

Cách 2: Dùng Vercel Deploy Hook

  1. Tại Vercel Project » Settings » Git » Cuộn xuống phần Deploy Hooks.
  2. Tạo một Deploy Hook với tên admin-publish, nhánh main. Vercel sẽ tạo cho bạn 1 đường link URL.
  3. Thêm biến môi trường VERCEL_DEPLOY_HOOK trong Vercel Settings với giá trị là đường link đó.
